# TANUPIO: NEON ARENA 1.4.0

PC・タブレット・スマートフォン対応のネオンアクションゲーム。

[今すぐプレイ](https://chi20253032.github.io/tanupio/)

## ゲームモード
- **SURVIVAL** — 無限ウェーブ。25体撃破後、低確率で隠しボス NULL Ω（HP 8,200）が出現。
- **STORY** — 専用ボスとストーリーを備えた全8ステージ。
- **AI DEMO** — 強化された自律AIのプレイを観戦。
- **AI CO-OP** — AIパートナーと協力して生き残る。
- **AI VERSUS** — 回避・射撃を行うAIライバルと対決。
- **SEASONAL RAID** — 日本時間のお正月、節分、ひな祭り、こどもの日、七夕、お盆、ハロウィン、クリスマスに開催。イベントごとの敵・ボス・クリア報酬を用意。
- **HALLOWEEN RAID** — 毎年10月31日（日本時間）限定。
- **ONLINE DUEL** — 1対1のオンライン対戦。
- **ONLINE CO-OP** — 招待ルームで最大10人のオンライン協力戦。

## 1.4.0 — 大型ゲームプレイ・オンライン拡張
- レベルアップ強化「オートファイア」を追加。取得後は最も危険な敵へ自動照準・連射。
- 遠距離攻撃を行うスナイパー型の敵と敵弾を追加。
- SURVIVALで25体撃破後、低確率でNULL Ω（HP 8,200）が乱入。
- AIの脅威優先度、距離管理、複数方向の回避、敵弾回避、スキル判断を強化。
- AI CO-OPの味方AI、AI VERSUSの戦闘AIを追加。
- 招待ルームを最大10人に拡張。参加者の入力・位置・HP・射撃・敵・弾をホスト基準で同期。
- WebSocket圧縮、送信サイズ制限、メッセージレート制御、ping/pong監視、低速クライアント対策を追加。
- 年中行事イベントに専用タイトルUI、専用敵・ボス、討伐報酬を追加。

## 1.3.0

## オンラインの遊び方
1. タイトル画面から「ONLINE PLAY」を選択。
2. 「オンラインモード」で「最大10人 協力」を選択。
3. 「ルームを作る」で招待コードを発行し、参加者に共有。
4. 参加者は「ルームに入る」からコードを入力。最大10人で同じ戦場に参加できます。

クイックマッチは従来どおり2人対戦・2人協力のペアリングです。最大10人協力は招待ルームを使用してください。

## 操作
- PC：WASD / 矢印キーで移動、マウスで照準、クリック / Spaceで射撃、Qでスキル。
- スマートフォン・タブレット：左スティックで移動、右スティックで照準・射撃、スキルボタンでスキル。

## 開発・テスト
Node.js 20以降が必要です。

```sh
npm install
npx playwright install --with-deps chromium
npm test
```

自動テストはマッチングサーバーの2人マッチ、モード分離、招待ルーム、10人上限、全参加者への状態リレー、およびブラウザ上の主要ゲームモードを検証します。
