# TANUPIO: NEON ARENA 1.3.0

**正式アップデート** — PC・タブレット・スマートフォン対応のネオンアクションゲーム。

[今すぐプレイ](https://chi20253032.github.io/tanupio/)

## ゲームモード

- **SURVIVAL** — 敵のウェーブを生き残る無限モード
- **STORY** — 物語付き全8ステージ。各戦域に専用の難易度・ボス・マップ進行を実装
- **AI DEMO** — AIパイロットの自律プレイを観戦。人間の操作入力は無効化され、レベルアップ報酬もAIが自動選択
- **HALLOWEEN RAID** — 2026年10月31日（日本時間）限定。パンプキン軍団を突破し、パンプキンキングを討伐して限定報酬を獲得
- **ONLINE DUEL** — 招待ルーム、公開ルーム、クイックマッチによる1対1対戦
- **ONLINE CO-OP** — 2人で同じ戦場に参加し、共有された敵を協力して倒すオンライン協力モード

## 1.3.0 — サウンド・ストーリー強化

- Web Audio APIによる効果音を追加。射撃、被弾、撃破、スキル、レベルアップ、ボス出現、ステージクリアなどに対応
- タイトル画面から効果音のON/OFFを切り替え可能
- ストーリーを5ステージから8ステージに拡張
- 各ステージに章タイトル、ストーリー文章、ミッション概要、専用ボスを追加
- 8ステージの進行マップをHUDに表示。クリア済み・現在・未到達のノードを視覚化
- ステージごとに敵のHP・速度・出現間隔・撃破目標・ボスHPを調整
- 最終ステージ「NEON END」は通常敵HP倍率5.2倍、速度1.9倍、ボスHP8,200の最高難易度
- レベルアップ強化を9種類から14種類へ拡張。クリティカル、経験値吸引、撃破時回復、貫通弾、複合火力強化を追加
- 既存オンライン・ハロウィン・AI・サバイバルでの回帰を検証

## 1.2.0 — オンライン強化

- ゲーム中に「退出」ボタンからタイトルへ戻れるように変更
- オンライン対戦は「もう一度プレイ」で接続を維持したまま再戦
- 2人協力プレイ、敵同期、味方射撃、モード別クイックマッチを追加

## HALLOWEEN RAID — 2026.10.31

10月31日限定の期間イベント。パンプキン敵を12体倒すとパンプキンキングが出現します。キングを撃破するとイベントクリア、限定報酬「パンプキンクラウン」とボーナススコアを獲得できます。開催判定は日本時間（Asia/Tokyo）です。

## 操作

PCはWASD / 矢印キー・マウス・Space・Q、タッチ端末は左右の仮想スティックとスキルボタンで操作できます。オートエイムはタイトル画面から切り替え可能です。

## オンライン

対戦・協力ともに招待ルーム、公開ルーム、クイックマッチを利用できます。協力モードは2人プレイです。オンライン接続は再戦時に維持されます。マッチングサーバーはRender Blueprintの `render.yaml` からデプロイ。ヘルスチェックは `/health`、接続先は `wss://tanupio-matchmaking.onrender.com` です。

## 開発・テスト

Node.js 20以降が必要です。

```sh
npm install
npx playwright install --with-deps chromium
npm test
```

自動テストでは、8ステージのストーリー進行、最終ステージ難易度、マップ表示、追加強化、効果音切替、サバイバル時の射撃、PC・スマホ操作、AI、ハロウィン、オンライン対戦・協力・再戦・途中退出を検証します。
