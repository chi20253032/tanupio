# TANUPIO: NEON ARENA 1.2.0

**正式アップデート** — PC・タブレット・スマートフォン対応のネオンアクションゲーム。

[今すぐプレイ](https://chi20253032.github.io/tanupio/)

## ゲームモード

- **SURVIVAL** — 敵のウェーブを生き残る無限モード
- **STORY** — 全5ステージ、ボス戦あり
- **AI DEMO** — AIパイロットの自律プレイを観戦。人間の操作入力は無効化され、レベルアップ報酬もAIが自動選択
- **HALLOWEEN RAID** — 2026年10月31日（日本時間）限定。パンプキン軍団を突破し、パンプキンキングを討伐して限定報酬を獲得
- **ONLINE DUEL** — 招待ルーム、公開ルーム、クイックマッチによる1対1対戦
- **ONLINE CO-OP** — 2人で同じ戦場に参加し、共有された敵を協力して倒すオンライン協力モード

## 1.2.0 — オンライン強化

- ゲーム中に「退出」ボタンからタイトルへ戻れるように変更。退出時はオンライン接続も適切に終了
- オンライン対戦は試合終了後の「もう一度プレイ」で同じWebSocket接続を維持したまま再戦
- 協力モードを追加。ホストが敵・スコアを管理し、参加者の射撃も敵に当たる。敵の位置・HPを同期
- クイックマッチは対戦と協力のモード別キューに分離
- 招待ルームにもモード情報を持たせ、ホストが選んだモードを参加者へ適用
- 協力プレイでは味方への誤射を防止

## HALLOWEEN RAID — 2026.10.31

10月31日限定の期間イベント。パンプキン敵を12体倒すとパンプキンキングが出現します。キングを撃破するとイベントクリア、限定報酬「パンプキンクラウン」とボーナススコアを獲得できます。開催判定は日本時間（Asia/Tokyo）です。

## 操作

PCはWASD / 矢印キー・マウス・Space・Q、タッチ端末は左右の仮想スティックとスキルボタンで操作できます。オートエイムはタイトル画面から切り替え可能です。

## オンライン

対戦・協力ともに招待ルーム、公開ルーム、クイックマッチを利用できます。協力モードは2人プレイです。オンライン接続は再戦時に維持されます。マッチングサーバーはRender Blueprintの `render.yaml` からデプロイ。ヘルスチェックは `/health`、接続先は `wss://tanupio-matchmaking.onrender.com` です。

## 開発・テスト

Node.js 20以降が必要です。

```sh
npm install
npx playwright install --with-deps chromium
npm test
```

自動テストでは、サーバーの対戦／協力キュー分離、ルームのモード情報、PCブラウザ2画面での招待対戦・クイックマッチ・再戦、2人協力時の敵同期と味方射撃、途中退出、PC操作、スマホタッチ操作、SURVIVAL / STORY / AI DEMO、ハロウィンボスと報酬を検証します。
