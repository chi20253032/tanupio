# TANUPIO: NEON ARENA 1.4.0

大型アップデート候補。PC・タブレット・スマートフォン対応。

[プレイ](https://chi20253032.github.io/tanupio/)

## モード
- SURVIVAL：無限戦闘。25体撃破後に低確率で隠しボス NULL Ω（HP 8,200）が出現。
- STORY：全8ステージ。
- AI DEMO：強化された自律AI。
- AI CO-OP：AIパートナーとの協力戦。
- AI VERSUS：AIライバルとの対決。
- SEASONAL RAID：日本時間のお正月、節分、ひな祭り、こどもの日、七夕、お盆、ハロウィン、クリスマスに開催する専用イベント。
- HALLOWEEN RAID：毎年10月31日限定。
- ONLINE DUEL：1対1。
- ONLINE CO-OP：招待ルームで最大10人の協力戦。

## 1.4.0
- オートファイア強化を追加。取得後は敵を自動照準して連射。
- 遠距離型スナイパーを追加。
- サバイバルに低確率のNULL Ω出現を追加。
- AIの脅威判定、回避、強化選択を改善。
- AI協力戦・AI対決を追加。
- オンライン招待ルームを最大10人に拡張し、参加者の位置・体力・射撃を同期。
- WebSocket圧縮、送信量制限、送信レート制御、ping/pong監視を追加。
- 季節ごとの専用ボス・報酬・タイトル画面イベントUIを追加。

## 1.3.0
- 効果音と8章ストーリー、進行マップを追加。
- 最終ステージは通常敵HP5.2倍、速度1.9倍、ボスHP8,200。
- レベルアップ強化を14種類に拡張。

## オンライン
10人協力はオンラインモードから「最大10人 協力」を選び、招待ルームを作成。クイックマッチは1対1。

## 開発
Node.js 20以降。`npm install` の後、`npm test` でサーバーとブラウザのテストを実行。

Version: 1.4.0 (release candidate; CI verification pending)
